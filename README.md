# Sobre o projeto

O **Tast Fashion** é um site desenvolvido com o objetivo de apresentar tendências, modelos e inspirações do mundo da moda. O projeto busca transmitir estilo, personalidade e elegância por meio de um layout moderno e visualmente atrativo.

## Objetivo

Criar uma página de moda que apresente diferentes peças e estilos, proporcionando uma experiência visual agradável aos visitantes.

## Modelos apresentados

- **Vest Romasa** — Strong & Charismatic.
- **Jacket Fima** — Strong Personality.
- **Jacket Black Kira** — Power Fascinating.

## Tecnologias utilizadas

- **HTML5:** estruturação e organização do conteúdo do site.
- **CSS3:** estilização, cores, fontes, posicionamento e organização dos elementos.
- **Google Maps:** integração do mapa para apresentar a localização.

## Desenvolvimento

O projeto foi desenvolvido utilizando HTML e CSS, colocando em prática conceitos de estruturação de páginas, estilização, organização de elementos e posicionamento de imagens e textos.
